# Acaochego 🐾

Projeto acadêmico desenvolvido para uma ONG fictícia de proteção animal.

## Sobre o projeto

O Acaochego é um projeto de site desenvolvido para apresentar uma organização voltada à proteção e ao cuidado com animais.

## Tecnologias utilizadas

- HTML5
- HTML semântico
- Formulários HTML
- Validação nativa de formulários

## Páginas

- Página inicial
- Projetos
- Cadastro

## Objetivo

Praticar a criação de páginas web utilizando estrutura semântica e formulários em HTML.
